# Agent instructions

The challenge statement in `docs/challenge.md` is the source of truth for scope and requirements.

## Core principles

1. **Code quality:** all code follows SOLID, KISS and Clean Code. Every function and class has a single responsibility.
2. **Language:** source code, identifiers (variables, functions, classes), comments, commit messages and technical logs are in English. Documentation aimed at end users or business stakeholders, such as READMEs and OpenAPI descriptions, is in Portuguese (pt-BR).
